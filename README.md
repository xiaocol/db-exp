# DBエクスポートツール

Oracle / PostgreSQL のテーブルを、**列を選んで・必要に応じてマスキング（脱敏）して** Excel（.xlsx）に出力する Web アプリケーションです。
単一の exe ファイルとして配布でき、ダブルクリックするとブラウザで画面が開きます。

- 対象DB: **Oracle（主対象）**、PostgreSQL
- 画面: React + shadcn/ui
- サーバー: FastAPI（ローカルPC上で `127.0.0.1` のみで待ち受け）
- 配布形態: PyInstaller による単一 exe（`db-exp.exe`）

---

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 接続管理 | Oracle（サービス名 / SID / TNS・接続文字列）、PostgreSQL の接続情報を保存。接続テスト可能 |
| 読み取り専用接続 | Oracle は `SET TRANSACTION READ ONLY`、PostgreSQL は読み取り専用セッションで接続。データを更新しません |
| テーブル選択 | スキーマ切替、表・ビュー・マテビューの一覧、**表名・論理名（コメント）で検索**（全角/半角を区別しない） |
| 列選択 | 出力列のチェック、列コメントを論理名として表示、主キー表示、見出しの任意変更 |
| マスキング | 氏名・住所・電話番号・メール・郵便番号・生年月日など**日本のデータ形式に合わせた規則**を列ごとに設定 |
| 自動判定 | 列名・コメントから個人情報らしき列を判定し、**テーブル選択時に自動でマスキングを設定**（安全側） |
| 抽出条件 | WHERE 句・ORDER BY 句・最大件数を指定可能 |
| プレビュー | マスキング適用後のデータを先頭 50 件表示 |
| 複数テーブル | 複数テーブルを 1 つの Excel ファイルにシート別で出力 |
| Excel 書式 | 日本語フォント（游ゴシック等）、全角幅を考慮した列幅、見出し固定、オートフィルタ、日付書式 `yyyy/mm/dd` |
| 見出し | 論理名 / 物理名 / 論理名＋物理名（2 行）を選択 |
| 大量データ | ストリーミング出力でメモリを圧迫しない。1,048,576 行を超えるとシートを自動分割 |
| 監査用情報 | 「エクスポート情報」シートに出力日時・接続先・件数・条件・マスキング内容を記録 |
| 設定の保存 | エクスポートリストと出力オプションを JSON で保存・再読込（定型作業の再実行に） |

マスキング規則の詳細は [docs/マスキング仕様.md](docs/マスキング仕様.md) を参照してください。

## 使い方（exe 版）

1. `db-exp.exe` をダブルクリックします。コンソール画面が開き、続いて既定のブラウザで画面が開きます。
   - ブラウザが開かない場合は、コンソールに表示された URL（例: `http://127.0.0.1:8765/`）を開いてください。
2. 左上の「接続先」→「新規」で接続情報を登録し、「接続」を押します。
3. スキーマを選び、テーブルをクリックします。
   - 個人情報の可能性がある列には自動でマスキングが設定されます（オレンジ色の枠）。内容を確認してください。
4. 出力する列のチェック、マスキング規則、抽出条件を設定し、「プレビュー」で結果を確認します。
5. 「エクスポートリストに追加」を押します（複数テーブルを追加できます）。
6. 右側でファイル名・見出し形式・フォントを選び、「Excelにエクスポート」を押すと、完了時に自動でダウンロードされます。
7. 終了するときはコンソール画面を閉じてください。

### 起動オプション

```
db-exp.exe --port 9000      待ち受けポートを指定（既定 8765。使用中なら自動で空きポートを使用）
db-exp.exe --no-browser     ブラウザを自動で開かない
```

## 設定・保存データ

保存先は `%APPDATA%\db-exp`（Windows）または `~/.db-exp`（Linux/macOS）です。
環境変数 `DBEXP_DATA_DIR` で変更できます。

| ファイル | 内容 |
| --- | --- |
| `connections.json` | 接続情報。パスワードは「パスワードを保存する」を選んだ場合のみ保存 |
| `settings.json` | 任意の設定ファイル（下記） |
| `exports\` | 生成した Excel の一時保存先。既定で 6 時間後に自動削除 |

### settings.json（任意）

```json
{
  "oracle_client_lib_dir": "C:\\oracle\\instantclient_19_20",
  "port": 8765,
  "export_retention_seconds": 21600
}
```

| キー | 説明 |
| --- | --- |
| `oracle_client_lib_dir` | Oracle Instant Client のフォルダ。指定すると **Thick モード**で接続（下記参照）。環境変数 `DBEXP_ORACLE_CLIENT_DIR` でも指定可 |
| `port` | 既定の待ち受けポート。環境変数 `DBEXP_PORT` でも指定可 |
| `export_retention_seconds` | エクスポートファイルの保持時間（秒） |

### Oracle の接続モードについて

- 既定は python-oracledb の **Thin モード**で、Oracle Client のインストールは不要です（対応: Oracle Database 12.1 以降）。
- **Oracle 11g 以前**に接続する場合や、Thin モード非対応の機能（一部の認証方式など）が必要な場合は、
  [Oracle Instant Client](https://www.oracle.com/jp/database/technologies/instant-client.html) を配置し、
  `oracle_client_lib_dir` を設定して Thick モードを使用してください。

### 日本語データについて

- Thin モードでは常に UTF-8 でデータを受信し、DB 側の文字コード（`JA16SJIS`、`JA16SJISTILDE`、`JA16EUC`、`AL32UTF8` 等）からの変換は DB サーバーが行います。追加設定は不要です。
- PostgreSQL は `client_encoding=UTF8` で接続します。
- 波ダッシュ（〜 / ～）、丸数字（①）、髙・𠮷 などの外字・異体字もそのまま出力されます。ただし DB 側の文字コードに存在しない文字は、格納時点で置換されている場合があります。
- `timestamp with time zone` 型は、PC のローカル時刻（日本では JST）に変換して出力します。

## セキュリティに関する注意

- サーバーは `127.0.0.1` のみで待ち受け、他の PC からは接続できません。
- 他サイトからの不正なリクエスト（CSRF・DNS リバインディング）を防ぐため、Host ヘッダーと独自ヘッダーを検証しています。
- 接続は読み取り専用です。さらに WHERE / ORDER BY 欄では `;`、コメント、更新系キーワードを拒否します。
- 「パスワードを保存する」を選ぶと、パスワードは**暗号化されず簡易的な難読化のみ**でユーザーフォルダに保存されます。共用 PC では保存しないでください。
- マスキングは**出力する Excel ファイルにのみ**適用され、DB のデータは変更しません。
- 自動判定は列名・コメントによる推定です。**出力前に必ずプレビューで確認してください。**

## ビルド方法

### 必要なもの

- Node.js 20 以上
- Python 3.10 以上

### Windows 用 exe の作成

PyInstaller はクロスコンパイルに対応していないため、**Windows 上で**実行してください。

```bat
scripts\build.bat
```

`dist\db-exp.exe` が生成されます（約 35MB）。この 1 ファイルを配布すれば動作します。

### Linux / macOS

```bash
./scripts/build.sh
```

`dist/db-exp` が生成されます。

### 手動でビルドする場合

```bash
# 1. フロントエンド
cd frontend
npm ci
npm run build          # frontend/dist が生成される

# 2. バックエンド＋exe
cd ../backend
python -m venv .venv
.venv/Scripts/pip install -r requirements-dev.txt    # Linux/macOS は .venv/bin/pip
.venv/Scripts/pyinstaller --noconfirm db_exp.spec    # backend/dist/db-exp(.exe) が生成される
```
