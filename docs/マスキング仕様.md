# マスキング仕様

マスキングは列単位で設定し、Excel への書き込み直前に適用されます。DB のデータは変更しません。
実装は `backend/app/masking.py` です。

## 共通ルール

- **NULL は NULL のまま**出力します（値が無いこと自体は秘匿情報ではないため）。
- 伏せ字は、**全角文字は全角「＊」、半角文字は半角「*」**で置き換え、見た目の桁数を保ちます。
- 空白（半角・全角スペース）は伏せずに残します。
- 数値・日付の列に文字列系の規則を適用した場合、文字列に変換してからマスキングします（日付は `yyyy/mm/dd` 形式）。
- マスキングした列は、Excel の見出しセルが**オレンジ色**になります。

## 規則一覧

| 規則 | 種別ID | 例 | パラメータ |
| --- | --- | --- | --- |
| そのまま出力 | `none` | — | — |
| 全桁マスク | `full` | `山田太郎` → `＊＊＊＊` | 伏せ字（空欄=自動） |
| 部分マスク | `partial` | `ABC12345` → `A******5` | 先頭に残す文字数、末尾に残す文字数 |
| 氏名（姓のみ残す） | `name` | `山田 太郎` → `山田 ＊＊` | — |
| ダミー氏名に置換 | `fake_name` | `山田 太郎` → `佐藤　花子` | 表記（漢字 / カナ） |
| メールアドレス | `email` | `taro@example.co.jp` → `t***@example.co.jp` | — |
| 数字のみマスク | `digits` | `03-1234-5678` → `**-****-5678` | 先頭に残す桁数、末尾に残す桁数（既定 4） |
| 郵便番号（上3桁のみ） | `postal` | `123-4567` → `123-****` | — |
| 住所（市区町村まで残す） | `address` | `東京都千代田区丸の内1-1` → `東京都千代田区＊＊＊＊` | — |
| 日付（年のみ残す） | `date_year` | `1985/04/01` → `1985/**/**` | — |
| 数値の丸め | `round_number` | `5,234,567` → `5,235,000` | 丸め桁（-3 = 千の位） |
| ハッシュ化（仮名化） | `hash` | `山田太郎` → `3f2a9c1b7d4e8a60` | 桁数（既定 16） |
| 固定値に置換 | `fixed` | 任意 → `＊＊＊` | 置換後の値 |
| 空欄（NULL）にする | `null` | 任意 → (空) | — |

### 各規則の詳細

**氏名（`name`）**
- 半角・全角スペースで区切られている場合、最初の区切りより前（姓）を残し、以降を伏せます。
  - `山田 太郎` → `山田 ＊＊`、`ヤマダ　タロウ` → `ヤマダ　＊＊＊`
- 区切りが無い場合は先頭 1 文字のみ残します。`山田太郎` → `山＊＊＊`
- カナ氏名・英字氏名にも使用できます。

**ダミー氏名（`fake_name`）**
- 元の値と「ハッシュ用ソルト」から決定的に選ぶため、**同じ人物は常に同じダミー氏名**になります。
- 候補は 20 姓 × 20 名 = 400 通りのため、別人が同じ名前になることがあります。突合せキーには `hash` を使用してください。

**数字のみマスク（`digits`）**
- 数字（全角数字を含む）のみを伏せ、ハイフン・括弧・空白などの区切り文字は残します。
  - `090(1234)5678` → `***(****)5678`
  - `０３－１２３４－５６７８` → `＊＊－＊＊＊＊－５６７８`
- 数字の桁数が「残す桁数」の合計以下の場合は、情報漏えい防止のため**すべて伏せます**。
- 電話番号・FAX・携帯番号、カード番号、口座番号などに使用します。

**住所（`address`）**
- 都道府県＋市区町村までを残し、町名・番地・建物名を `＊＊＊＊` に置き換えます。
- 政令指定都市の区（`横浜市中区`）、郡（`北佐久郡軽井沢町`）にも対応しています。
- 先頭に郵便番号（`〒100-0005 ` 等）がある場合は、郵便番号の下 4 桁も伏せます。
- 住所として解釈できない値は、先頭 3 文字のみ残します。
- 市区町村の判定は文字パターンによるため、`四日市市` のように地名に「市」を含む場合など、まれに残す範囲が短くなることがあります（伏せる側に倒れるため情報漏えいにはなりません）。

**日付（`date_year`）**
- 日付型は年のみ残して `1985/**/**` とします。
- 文字列の場合、先頭の西暦 4 桁（全角可）を残します。和暦（`昭和60年4月1日`）は `昭和60年＊＊月＊＊日` とします。

**ハッシュ化（`hash`）**
- `SHA-256(ソルト + 値)` の先頭 N 桁（16 進）を出力します。
- 同じソルトなら同じ値は同じハッシュになるため、**テーブル間の突合せキー**として使えます。
- ソルトを指定しない場合、電話番号など候補の少ない値は総当たりで推測される可能性があります。社外に渡す場合はソルトを指定してください（ソルトは Excel やエクスポート情報シートには出力されません）。

## 自動判定ルール

テーブル選択時、列名と列コメント（論理名）から次の順に判定し、最初に一致した規則を初期設定します。
大文字・小文字は区別しません。

| 順 | 判定キーワード（コメント / 列名） | 設定される規則 |
| --- | --- | --- |
| 1 | パスワード、暗証、PASSWORD、PASSWD、PWD | 空欄（NULL） |
| 2 | マイナンバー、個人番号、MY_NUMBER、KOJIN_BANGO | 全桁マスク |
| 3 | メール、MAIL、EMAIL | メールアドレス |
| 4 | 郵便、〒、ZIP、POST_CODE、POSTAL_NO、YUBIN | 郵便番号 |
| 5 | 住所、所在地、ADDR、JUSHO | 住所 |
| 6 | 電話、携帯、TEL、PHONE、FAX、MOBILE、DENWA | 数字のみ（末尾 4 桁） |
| 7 | カード、口座、CARD_NO、CREDIT、ACCOUNT_NO、KOUZA | 数字のみ（末尾 4 桁） |
| 8 | 生年月日、誕生日、BIRTH、SEINENGAPPI | 日付（年のみ） |
| 9 | 氏名、名前、姓名、フリガナ、顧客名・会員名・社員名など、SHIMEI、FULL_NAME、SEI、MEI、KANA_NAME など | 氏名 |

- `商品名` や `PRODUCT_NAME` のように、人名以外の「名」は対象外です。
- 判定ルールは `backend/app/masking.py` の `_SUGGEST_PATTERNS` で変更できます。
- **自動判定は推定です。** 出力前に必ずプレビューで確認してください。

## 規則の追加方法

1. `backend/app/masking.py` にマスク関数 `def _xxx(value, params) -> Any` を追加する。
2. `_SIMPLE_RULES`（ソルトを使う場合は `_SALTED_RULES`）に登録する。
3. `RULE_DEFINITIONS` に表示名・例・パラメータ定義を追加する（画面の選択肢は自動で反映されます）。
4. `backend/tests/test_masking.py` にテストを追加する。
