# 開発ガイド

## 構成

```
db-exp/
├── backend/                  FastAPI（Python）
│   ├── app/
│   │   ├── main.py           アプリ本体・セキュリティ対策・SPA 配信
│   │   ├── config.py         保存先パス・settings.json の読込
│   │   ├── schemas.py        API の入出力モデル（Pydantic）
│   │   ├── store.py          接続プロファイルの保存・接続中セッション管理
│   │   ├── masking.py        マスキング規則
│   │   ├── categories.py     個人情報の種類（列名パターン・値の検査・姓の辞典）
│   │   ├── detector.py       列の自動判定（列名・論理名・型・サンプル値からスコア算出）
│   │   ├── textscan.py       文中の個人情報の検出（項目名：値、敬称、電話番号等）
│   │   ├── findings.py       判定結果（Finding）の生成・人の判断の適用
│   │   ├── dbscan.py         DB の一括スキャン（バックグラウンドジョブ）
│   │   ├── documents.py      ドキュメントの読込（xlsx/csv/txt/md）・判定・Markdown 出力
│   │   ├── report.py         判定結果一覧の Excel 出力
│   │   ├── exporter.py       エクスポートジョブ（Excel / INSERT 文 / UPDATE 文）
│   │   ├── sqlgen.py         SQL 出力（型の分類・リテラル・UPDATE 用の SQL 式）
│   │   ├── db/
│   │   │   ├── base.py       DB 方言の基底クラス・SQL 断片チェック
│   │   │   ├── oracle.py     Oracle（python-oracledb）
│   │   │   └── postgres.py   PostgreSQL（psycopg 3）
│   │   └── routers/          API ルーティング
│   ├── tests/                pytest
│   ├── run.py                exe のエントリーポイント（サーバー起動＋ブラウザ表示）
│   └── db_exp.spec           PyInstaller ビルド定義
├── frontend/                 React + TypeScript + Vite + shadcn/ui
│   └── src/
│       ├── App.tsx           データベース / ドキュメントの切替
│       ├── lib/findings.ts   判定結果と人の判断の扱い
│       ├── lib/api.ts        API クライアント
│       ├── lib/types.ts      型定義
│       └── components/       画面部品（ui/ は shadcn/ui が生成したもの）
├── scripts/                  ビルド・開発用スクリプト
└── docs/
```

## 処理の流れ

```
ブラウザ（React）
  │  /api/*（JSON, X-DBEXP ヘッダー付き）
  ▼
FastAPI ── store ── 接続プロファイル（connections.json）／接続中パスワード（メモリ）
  │
  ├─ db/oracle.py, db/postgres.py   ── メタデータ取得・SELECT 実行（読み取り専用）
  ├─ dbscan.py → detector.py        ── 一括スキャン（列情報＋先頭 200 件で判定）→ Finding の一覧
  ├─ masking.py                     ── 列ごとのマスク関数を生成
  └─ exporter.py                    ── バックグラウンドスレッドで出力
        ├─ Excel                         → exports/<job_id>.xlsx
        └─ sqlgen.py（INSERT / UPDATE）  → exports/<job_id>.sql

ドキュメント（アップロード）
  └─ documents.py ── uploads/<scan_id>/ に保存 → 表は detector、文章は textscan で判定
                     → 人の判断を受け取り、マスク済み Markdown＋結果一覧を ZIP で返す
```

- 判定結果（Finding）は「マスキング対象（auto）」と「要確認（review）」に分かれます。人の判断（Decision）は画面側で保持し、
  出力時にまとめて送ります。判断の無い要確認は、サーバー側では安全のため推奨規則でマスクします（画面では未判断が残っていると出力できません）。
- Finding の ID は「ファイル・表＋場所＋列（文中は種類・語句）」から作るため、同じファイルを再スキャンしても判断を引き継げます。
- アップロードしたファイルと DB のスキャン結果は、`export_retention_seconds`（既定 6 時間）を過ぎると削除されます。

- DB 接続はリクエストごとに確立・切断します（コネクションプールは使用しません）。
- エクスポートはスレッドで実行し、画面は 0.5 秒ごとに進捗を取得します。
- SQL に埋め込む列名は、**必ず DB のメタデータと照合済みの名前のみ**をダブルクォートで囲んで使用します。

## 開発環境の構築

```bash
# バックエンド
cd backend
python -m venv .venv
.venv/bin/pip install -r requirements-dev.txt     # Windows: .venv\Scripts\pip

# フロントエンド
cd ../frontend
npm ci
```

### 起動

```bash
./scripts/dev.sh
```

- バックエンド: http://127.0.0.1:8765 （`--reload` 付き）
- フロントエンド: http://localhost:5173 （`/api` はバックエンドへプロキシ）

Windows の場合は 2 つのターミナルで次を実行してください。

```bat
cd backend && .venv\Scripts\python -m uvicorn app.main:app --port 8765 --reload
cd frontend && npm run dev
```

### shadcn/ui コンポーネントの追加

```bash
cd frontend
npx shadcn@latest add <コンポーネント名>
```

## テスト

```bash
cd backend
.venv/bin/python -m pytest
```

実 DB を使う結合テストは、環境変数を設定した場合のみ実行されます。
`tests/test_db_sql.py` は日本語のサンプル表（`DBEXP_T_KOKYAKU`）を作成し、一括スキャン → INSERT 文の投入 → UPDATE 文の実行を行い、
**INSERT 文（Python でマスク）と UPDATE 文（DB の関数でマスク）の結果が一致すること**を確認します。

```bash
DBEXP_TEST_PG=localhost:5432/postgres/postgres/パスワード \
DBEXP_TEST_ORACLE=localhost:1521/FREEPDB1/appuser/パスワード \
.venv/bin/python -m pytest
```

テスト用 DB は Docker で用意できます。

```bash
docker run -d --name test-pg  -e POSTGRES_PASSWORD=test -p 5432:5432 postgres:16
docker run -d --name test-ora -e ORACLE_PASSWORD=test -e APP_USER=appuser -e APP_USER_PASSWORD=apppw \
  -p 1521:1521 gvenzl/oracle-free:slim
```

## API 一覧

POST / DELETE には `X-DBEXP: 1` ヘッダーが必須です（CSRF 対策）。エラー時は HTTP 400 と `{"detail": "日本語メッセージ"}` を返します。

| メソッド | パス | 内容 |
| --- | --- | --- |
| GET | `/api/health` | 稼働確認 |
| GET | `/api/connections` | 接続一覧 |
| POST | `/api/connections` | 接続の作成・更新（`id` 指定で更新） |
| DELETE | `/api/connections/{id}` | 接続の削除 |
| POST | `/api/connections/test` | 保存前の接続テスト |
| POST | `/api/connections/{id}/connect` | 接続（パスワードをメモリに保持） |
| POST | `/api/connections/{id}/disconnect` | 切断 |
| GET | `/api/connections/{id}/schemas` | スキーマ一覧と既定スキーマ |
| GET | `/api/connections/{id}/tables?schema=` | 表・ビュー一覧（コメント・概算件数付き） |
| GET | `/api/connections/{id}/columns?schema=&table=&sample=` | 列一覧（コメント・型・主キー・自動判定）。`sample` 件の値も判定に使う |
| POST | `/api/connections/{id}/scan` | 一括スキャン開始（`schema_name`, `tables`, `sample_rows`） |
| GET | `/api/scan/{job_id}` | 一括スキャンの進捗・結果（結果は完了時のみ） |
| POST | `/api/scan/{job_id}/cancel` | 一括スキャンの中止 |
| POST | `/api/documents/scan` | ドキュメントのスキャン（multipart、`files`。ファイル名にフォルダを含められる） |
| POST | `/api/documents/{scan_id}/export` | 人の判断を反映したマスク済み Markdown（ZIP） |
| DELETE | `/api/documents/{scan_id}` | アップロードしたファイルの削除 |
| POST | `/api/report` | 判定結果一覧（Excel。元の値は含まない） |
| GET | `/api/masking/categories` | 個人情報の種類と既定の規則 |
| GET | `/api/masking/rules` | マスキング規則の定義（画面の選択肢） |
| POST | `/api/masking/test` | マスキング規則の動作確認 |
| POST | `/api/preview` | マスキング適用後のプレビュー |
| POST | `/api/export` | エクスポート開始（ジョブ ID を返す）。`options.format` = `xlsx` / `sql_insert` / `sql_update` |
| GET | `/api/export/{job_id}` | 進捗取得 |
| POST | `/api/export/{job_id}/cancel` | 中止 |
| GET | `/api/export/{job_id}/download` | 出力ファイル（.xlsx / .sql）のダウンロード |

FastAPI の自動ドキュメントは起動中に http://127.0.0.1:8765/docs で参照できます。

## exe 化に関する注意

- `db_exp.spec` でフロントエンドの `frontend/dist` を `static/` として同梱しています。先にフロントエンドをビルドしてください。
- python-oracledb の Thin モードは `cryptography` を C 拡張内部から遅延 import するため、PyInstaller の自動解析で検出されません。
  spec で明示的に同梱しています（外すと exe 実行時に `DPY-3016` エラーになります）。
- `scripts/build.bat` は日本語版 Windows の cmd で文字化けしないよう **Shift_JIS(CP932)・CRLF** で保存しています。編集時は文字コードに注意してください。
- ウイルス対策ソフトが PyInstaller 製 exe を誤検知する場合があります。社内配布時はコード署名を検討してください。
